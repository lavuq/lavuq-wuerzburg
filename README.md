# LAVUQ Würzburg – Website MVP

Statische, responsive Website für das LAVUQ-Freundschaftskonzept.

## Enthalten
- Startseite
- Sicherheitsseite
- FAQ
- 4-stufiges Bewerbungsformular mit 9 Fragen zur Gruppenzusammenstellung
- Impressum- und Datenschutz-Platzhalter
- responsive Navigation
- eigenes SVG-Q/Favicon

## Start lokal
`index.html` im Browser öffnen oder z. B. `python -m http.server 8000` im Ordner ausführen.

## Vor dem Livegang
1. Impressum mit echten Angaben füllen.
2. Datenschutzerklärung an Hosting, Formularspeicherung und eingesetzte Dienste anpassen.
3. Bewerbungsformular an Backend/Form-Dienst anbinden (aktuell werden keine Daten versendet).
4. Markenname LAVUQ vor kommerzieller Nutzung rechtlich final prüfen.
5. Optional Domain, E-Mail, Analytics und Spam-Schutz einrichten.
